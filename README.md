# spatialDiD-simulation-code

The code included in this repository is designed to reproduce the tables initially generated for the simulation experiment provided in the appendix of our paper, ``Bayesian Hierarchical Spatial Difference-in-Difference Models''. All code used to obtain posterior samples, compute credible intervals, and evaluate model performance is included in the R Markdown file titled *reproducibility-guide-spatial-DiD-simulation-code.Rmd*.
